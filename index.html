INSTALL
  1. If an older JeBlock test profile is installed, remove it first.
  2. Tap Protect this iPhone and open the downloaded .mobileconfig.
  3. Open Settings → Profile Downloaded → Install.
  4. Toggle Airplane Mode on/off once, then run the benchmark.

If “Profile Downloaded” is missing: Settings → General → VPN & Device Management.

Developer test profiles

Only use one DNS profile at a time. These are here so we can benchmark the filters on your exact iPhone before choosing the final JeBlock backend.

Remove the currently installed JeBlock profile before switching profiles.

IMPORTANT

This version improves the DNS layer. DNS can block ad and tracking hosts across the phone, but a PWA cannot install a Safari content-blocker extension. Popups or same-domain ads that survive DNS require the separate Safari extension layer we will build next.
