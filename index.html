Ready to protect

One profile. Maximum DNS-level ad and tracker blocking.

INSTALL
  1. Tap Protect this iPhone.
  2. Open the downloaded .mobileconfig file in Safari Downloads.
  3. Open Settings → Profile Downloaded → Install.
  4. Come back and tap Check protection.

If “Profile Downloaded” is missing: Settings → General → VPN & Device Management.

Having trouble?

Maximum protection is intentionally aggressive. If a site or app stops working, install Compatibility mode instead.

To fully remove JeBlock: Settings → General → VPN & Device Management → JeBlock → Remove Profile.

BETA NOTE

JeBlock V0.2 uses an aggressive public DNS filter while we build our own backend. DNS blocking can stop many ads, trackers and pop-up sources, but it cannot guarantee 99% on every site or block ads delivered from the same domain as the content.
