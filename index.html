INSTALL
  1. Remove the currently installed JeBlock test profile first.
  2. Tap Protect this iPhone and open the downloaded .mobileconfig.
  3. Open Settings → Profile Downloaded → Install.
  4. Toggle Airplane Mode on/off once, then test Safari and the Apple apps where you normally see ads.

If “Profile Downloaded” is missing: Settings → General → VPN & Device Management.

Developer test profiles

Only use one DNS profile at a time. If Maximum causes a problem or scores worse, use the previous OISD-only profile so we can compare on the same iPhone.

Remove the currently installed JeBlock profile before switching profiles.

IMPORTANT

Maximum targets Apple advertising/tracking domains, but it does not block all Apple services and it cannot guarantee every in-app ad disappears. DNS also cannot remove same-domain ads or page elements; browser-level filtering is a separate layer.
